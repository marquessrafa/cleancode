## CleanCode 1.4.10 — Atualizações aparecem poucos minutos depois de saírem

### Downloads

| Sistema | Arquivo |
|---|---|
| macOS 12+ (Apple Silicon) | `CleanCode-1.4.10-macOS-Apple-Silicon.dmg` |
| macOS 12+ (Intel) | `CleanCode-1.4.10-macOS-Intel.dmg` |
| Windows 10/11 64 bits | `CleanCode-1.4.10-Windows-x64.exe` |

### Atualizações

- **Quando o app verifica:**
  - 15 s depois de abrir e depois a cada **3 minutos** (antes eram 30). O feed é um arquivo de poucas centenas de bytes;
  - ao acordar do repouso (`powerMonitor resume`, 8 s depois, para a rede voltar) e ao desbloquear a tela;
  - quando a janela principal ganha foco e quando o painel da barra de menus abre.

  Essas checagens extras acontecem no máximo uma vez a cada 2 minutos.
- **Fonte:** o feed continua sendo lido do repositório (`raw.githubusercontent`, com cache de até 5 min) e dos anexos do Release mais recente (`releases/latest/download`), que ficam disponíveis assim que o Release é publicado. O app fica com a versão mais nova das duas.
- **Sem repetição:**
  - o popup "disponível" aparece uma vez por versão;
  - as verificações automáticas não mudam o botão do topo para "verificando";
  - uma falha de rede numa verificação automática não aparece como erro (a manual continua mostrando).
- **Ressalva:** quem ainda está numa versão anterior verifica a cada 30 minutos até instalar esta.
